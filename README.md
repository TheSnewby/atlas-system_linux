# Atlas System Linux

A set of recreations of Linux and system functions that give the system so much capability. I found this curriculum eye-opening as the low-level capabilities of the system were laid bare for analysis and usage.

[Atlas Shell v2 Project Page](https://github.com/TheSnewby/atlas-shell_v2)
[Stephen Newby's LinkedIn Profile](https://www.linkedin.com/in/stephenjnewby/)

## Description
* 0x08_CPython - a C/Python interface library that allows C to be ported to Python and visa-versa
* Getline - reads an entire line from a file descriptor
* Libasm - used Assembly to recreate some string.h functions
* Ls - Lists the files and folders in a directory with varying degrees of details
* Multithreading - Uses a combination of process threads and mutexes to utilize multiple threads without getting race conditions
* Nm_objdump - reads and displays symbol tables
* Proc_filesystem - A virtual filesystem acting as a dynamic interface to read and affect ongoing processes.
* Readelf - reads and displays the meta data of an ELF file
* Signals - the ability to send, receive, capture, and change system signals
* Sockets - the capability to send and receive messages through ports
* Strace - the tracking of system calls made by a process.
